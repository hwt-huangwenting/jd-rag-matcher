# 某公司 · AI 应用开发实习生（深圳，智能体方向）

## 工作信息

- 岗位名称：AI 应用开发实习生（智能体方向）
- 工作地点：深圳
- 实习安排：5 天/周，6 个月
- 学历要求：学历不限

## 任职要求

1. 愿意付出 6 个月实习周期扎实成长（只有 3 个月左右实习期的同学勿投简历）。
2. 愿意从事 AI 智能体应用技术（ClaudeCode、RAG、Skill、MCP 等）的开发。
3. 熟悉 C / Python / Java / C# 等一门高级语言优先。
4. 认同通过技术创新创造价值，具备极强的学习力与耐挫折力。
5. 较强的逻辑推理与分析能力。
6. 具有良好的团队合作精神与沟通能力。
7. 有实际项目开发经验（学校导师项目 / 开源项目 / 其他）优先。

## 岗位说明

- 参与全栈技术项目实践，与 Web 与 AI 智能体方向的技术人员协作。
- 工作内容围绕 AI 智能体应用开发，而非传统后端业务开发。
